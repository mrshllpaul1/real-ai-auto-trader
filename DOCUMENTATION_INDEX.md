## 🆘 Can't Find a File?

1. **Check the root directory**: All docs are at `/app/`
2. **Use search**: `find . -name "*.md" -o -name "*.txt"`
3. **List all docs**: `ls -la *.md *.txt`
4. **Check git**: `git ls-files | grep -E '\.(md|txt)$'`

## 📝 Adding New Documentation

When creating new documentation:
1. Place it in the root directory
2. Use descriptive filenames (UPPERCASE_WITH_UNDERSCORES.md)
3. Add an entry to this index file
4. Link it from README.md if appropriate
