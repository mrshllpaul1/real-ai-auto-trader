💡 KEY TAKEAWAYS
================================================================================

The report_progress tool is:
✓ A "smart save" that commits + pushes + updates PR
✓ Used after completing meaningful work
✓ Essential for tracking progress in Emergent platform
✓ Best used frequently (early and often)
✓ Requires clear commit messages and checklists

Basic Usage:
report_progress(
  commitMessage: "Brief one-line description",
  prDescription: "Markdown checklist with [x] and [ ]"
)

What It Does Automatically:
1. git add .
2. git commit -m "message"
3. git push origin branch
4. Update PR description
